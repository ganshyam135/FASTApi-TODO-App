# FastAPI TODO API

A REST API built using FastAPI that allows users to manage TODO tasks with authentication.

This project was created to learn backend API development, authentication, and database interactions using FastAPI.

---

# Features

User Authentication
- JWT-based login
- Password hashing

TODO Management
- Create TODO
- Update TODO
- Delete TODO
- View TODOs

Admin Features
- Admin-only routes
- Manage user TODOs

Database
- SQLite database
- SQLAlchemy ORM

Testing
- Unit tests using Pytest

---
